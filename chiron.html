Chiron

A programming language of my own design.

Chiron is a language I designed from scratch. Instead of the usual curly braces and keywords, it uses a block-and-symbol syntax: blocks are wrapped in *stars*, variables live between :colons:, and commands start with a ^caret^. It supports functions, objects, loops, conditionals, imports, and async — all run by an interpreter written in Python.

A taste of Chiron
*file*
 :filetype:"code"
 :purpose:"Fibonacci"
 *code*
  :f1:0
  :f2:1
  :list: = [0, 1]

  *func*fib*
   :f3: = :f1: + :f2:
   ^append^:list::f3:
   ^say^:f3:
   :f1: = :f2:
   :f2: = :f3:
  *func*^end^

  ^ask^:t:"How many numbers? "
  *loop* :x: from 1 to :t:*
   ^call^fib
  *loop*^end^
 *code*^end^
*file*^end^

Run a program with python3 interpreter.py yourfile.chi — or just open the .chi file in Atlas, which runs it for you.

Language features
🧩

Functions & objects

*func* and *obj* blocks with properties and methods.

🔁

Loops & conditionals

Counting, for-each, while, and *if* / *else* control flow.

📦

Imports

Pull in other files — whole, or by line range.

⚡

Async

*async* blocks run concurrently and share globals.

📄

Plaintext mode

A Markdown-like rendering mode with headings, lists and inline color.

🛠️

Self-editing

File ops like [changeline] let a program rewrite its own source.

💪

Weakly typed

Weakly typed, so your code doesn't throw many errors if you change a variable's kind.
