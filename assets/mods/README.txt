Drop your mod .jar files in this folder.

The website links to them by filename, e.g. the "Too Many Additions" card uses:
    <a class="card" href="assets/mods/too-many-additions.jar" download> … </a>

So save that mod's jar here as:  too-many-additions.jar

Notes:
- The filename in the href must match the file exactly (case-sensitive).
- When you publish to GitHub Pages, commit the .jar files too so they're downloadable.
- Large jars are fine, but GitHub has a 100 MB per-file limit; for bigger files link to
  a Modrinth/CurseForge direct-download URL instead.
